
# Network Topology and IP Configuration

## 1. Network Overview

The VM uses two independent network adapters.

| Adapter | Purpose | Guest Interface |
|---|---|---|
| Adapter 1 | NAT internet access | enp0s3 |
| Adapter 2 | Host-only management | enp0s8 |

## 2. Host-only Network

| Parameter | Value |
|---|---|
| Network | 192.168.56.0/24 |
| Host interface | vboxnet0 |
| Host IP | 192.168.56.1 |
| Guest interface | enp0s8 |
| Guest IP | 192.168.56.10 |
| Guest gateway | Not configured on this interface |
| DHCP | Disabled |

The static guest IP is configured using Netplan.

Configuration file:

`/etc/netplan/50-cloud-init.yaml`

Relevant configuration:

```yaml
network:
  version: 2
  ethernets:
    enp0s3:
      dhcp4: true
    enp0s8:
      dhcp4: false
      addresses:
        - 192.168.56.10/24
```

## 3. NAT Network

| Parameter | Value |
|---|---|
| Guest interface | enp0s3 |
| Guest IP | 10.0.2.15 |
| Gateway | 10.0.2.2 |
| Address assignment | DHCP |
| Purpose | Outbound internet |

The NAT interface provides the default route and internet access.

## 4. Routing

Expected default route:

`default via 10.0.2.2 dev enp0s3`

The host-only network is used for private management and does not
replace the NAT default route.

## 5. Connectivity Verification

Host-to-guest management:

```bash
ping -c 4 192.168.56.10
ssh devopsadmin@192.168.56.10
```

Guest internet connectivity:

```bash
ping -c 4 1.1.1.1
curl -I https://cloudflare.com
```

Guest interface and route verification:

```bash
ip -br addr
ip route
```

## 6. External Connectivity

Cloudflare Quick Tunnel provides an external HTTPS entry point.

It avoids the need for direct inbound router port forwarding.

The temporary hostname is generated by Cloudflare and can change
when the tunnel restarts.

## 7. Network Limitations

- No router administration access was available.
- No router port forwarding was configured.
- No dedicated public static IP was configured.
- No custom DNS A record was created.
- Cloudflare Quick Tunnel is used instead of direct public routing.
